# QuakeC virtual machine

[← Documentation index](../README.md) · [Source index](../source-index.md)

Quake's *game rules* (monsters, weapons, doors, items, scoring) are not written in C. They are in a QuakeC program, `progs.dat`,
compiled to bytecode and run by a small virtual machine inside the engine. The C side only provides entities (*edicts*), physics and
about 90 **builtin functions** that the bytecode can call. All of it runs on the server, which in single player is the same process.

| File | Role |
| --- | --- |
| [`pr_comp.h`](#pr_comph) | Bytecode format: opcodes, statements, definitions, functions |
| [`progdefs.h`, `progdefs.q1`, `progdefs.q2`](#progdefsh-progdefsq1-progdefsq2) | The C layout of QuakeC's global and entity variables |
| [`progs.h`](#progsh) | Edicts, `eval_t`, accessor macros, VM globals |
| [`pr_edict.c`](#pr_edictc) | Loading `progs.dat`, edict allocation, entity text parsing, saving |
| [`pr_exec.c`](#pr_execc) | The interpreter |
| [`pr_cmds.c`](#pr_cmdsc) | The builtins (`PF_*`) |

```
progs.dat (in pak0.pak)         PR_LoadProgs ──► pr_functions, pr_statements, pr_globals, pr_strings
maps/e1m1.bsp "entities" lump   ED_LoadFromFile ──► edicts + fields set from key/value text
SV_Physics ─► think/touch/use ─► PR_ExecuteProgram(func) ─► opcodes ─► builtins (PF_setorigin, PF_sound, ...)
```

## `pr_comp.h`

Shared with the QuakeC compiler (`qcc`). It defines the on-disk format.

```c
typedef enum { ev_void, ev_string, ev_float, ev_vector, ev_entity, ev_field, ev_function, ev_pointer } etype_t;

#define OFS_RETURN 1     // a function's return value lives at global offset 1..3
#define OFS_PARM0  4     // parameter n at 4 + 3n (three slots each, so a vector fits)

enum { OP_DONE, OP_MUL_F, OP_MUL_V, OP_MUL_FV, OP_MUL_VF, OP_DIV_F, OP_ADD_F, OP_ADD_V, OP_SUB_F, OP_SUB_V,
       OP_EQ_F, ..., OP_LOAD_F, OP_LOAD_V, OP_LOAD_S, OP_LOAD_ENT, ..., OP_STORE_F, ..., OP_STOREP_F, ...,
       OP_RETURN, OP_NOT_F, ..., OP_IF, OP_IFNOT, OP_CALL0 ... OP_CALL8, OP_STATE, OP_GOTO, OP_AND, OP_OR, OP_BITAND, OP_BITOR };

typedef struct statement_s { unsigned short op; short a, b, c; } dstatement_t;   // an instruction: op + three global offsets
typedef struct { unsigned short type; unsigned short ofs; int s_name; } ddef_t;   // a global or field definition
typedef struct {
	int first_statement;     // negative = a builtin: -n is builtin number n
	int parm_start, locals;
	int profile;             // runtime counter for the `profile` command
	int s_name, s_file, numparms;
	byte parm_size[MAX_PARMS];
} dfunction_t;

typedef struct { int version; int crc; int ofs_statements, numstatements, ...; int entityfields; } dprograms_t;   // the file header
```

A QuakeC instruction is `a OP b → c`, where `a`, `b`, `c` are offsets into one big array of 32-bit slots (`pr_globals`). `PROG_VERSION` is 6.

## `progdefs.h`, `progdefs.q1`, `progdefs.q2`

Generated by `qcc` ("file generated by qcc, do not modify"). They describe the **C structs that overlay the first part of the QuakeC
globals and the entity fields**:

```c
typedef struct {                   // the first globals of every progs.dat
	int pad[28];                   // OFS_RETURN, OFS_PARM*...
	int self, other, world;
	float time, frametime, force_retouch;
	string_t mapname;
	float deathmatch, coop, teamplay, serverflags;
	float total_secrets, total_monsters, found_secrets, killed_monsters;
	float parm1, parm2, ... parm16;
	vec3_t v_forward, v_up, v_right;
	float trace_allsolid, trace_startsolid, trace_fraction;
	vec3_t trace_endpos, trace_plane_normal;
	float trace_plane_dist;  int trace_ent;  float trace_inopen, trace_inwater;
	int msg_entity;
	func_t main, StartFrame, PlayerPreThink, PlayerPostThink, ClientKill, ClientConnect,
	       PutClientInServer, ClientDisconnect, SetNewParms, SetChangeParms;
} globalvars_t;

typedef struct {                   // entity fields every progs has (entvars_t)
	float modelindex;  vec3_t absmin, absmax;  float ltime, movetype, solid;
	vec3_t origin, oldorigin, velocity, angles, avelocity, punchangle;
	string_t classname, model;  float frame, skin, effects;
	vec3_t mins, maxs, size;
	func_t touch, use, think, blocked;  float nextthink;  int groundentity;
	float health, frags, weapon; string_t weaponmodel; float weaponframe, currentammo,
	      ammo_shells, ammo_nails, ammo_rockets, ammo_cells, items, takedamage;
	int chain; float deadflag; vec3_t view_ofs; float button0, button1, button2, impulse, fixangle;
	vec3_t v_angle; float idealpitch; string_t netname; int enemy; float flags, colormap, team,
	      max_health, teleport_time, armortype, armorvalue, waterlevel, watertype, ideal_yaw, yaw_speed;
	int aiment, goalentity; float spawnflags; string_t target, targetname; float dmg_take, dmg_save;
	int dmg_inflictor, owner; vec3_t movedir; string_t message; float sounds; string_t noise, noise1, noise2, noise3;
} entvars_t;
```

`progdefs.h` includes `progdefs.q2` if `QUAKE2` is defined, otherwise `progdefs.q1` (the one used here). `PR_LoadProgs` refuses a `progs.dat` whose header CRC does not match `PROGHEADER_CRC`
(5927 in `progdefs.q1`), so a game with a different set of built-in variables cannot be loaded by mistake.

```c
// from C, a QuakeC field is just a struct member:
ent->v.origin[2] += 20;
if ((int)ent->v.flags & FL_MONSTER && ent->v.health > 0) { ... }
pr_global_struct->time = sv.time;
```

## `progs.h`

```c
typedef union eval_s {                 // one 32-bit QuakeC value
	string_t string;  float _float;  float vector[3];  func_t function;  int _int;  int edict;
} eval_t;

typedef struct edict_s {
	qboolean free;
	link_t   area;                      // linked into the world's area tree
	int      num_leafs;  short leafnums[MAX_ENT_LEAFS];    // BSP leaves it touches
	entity_state_t baseline;            // initial state sent to clients
	float    freetime;                  // sv.time when freed, so slots are not reused immediately
	entvars_t v;                        // the C-visible QuakeC fields
	// fields only QuakeC knows follow immediately after (pr_edict_size is the full size)
} edict_t;
```

Edicts are **variable-sized** (the progs decide how many extra fields exist), so never index `sv.edicts` as an array:

```c
edict_t *e = EDICT_NUM (n);            // the nth
e = NEXT_EDICT (e);                    // the next one
int  n = NUM_FOR_EDICT (e);
int  p = EDICT_TO_PROG (e);            // byte offset: how an entity is stored in a QuakeC value
edict_t *e2 = PROG_TO_EDICT (p);
```

Accessors for the VM's globals and parameters: `G_FLOAT(o)`, `G_INT(o)`, `G_EDICT(o)`, `G_VECTOR(o)`, `G_STRING(o)`, `G_FUNCTION(o)`, and for fields `E_FLOAT(e, o)` and similar.

```c
// a builtin reading its parameter and returning a value (pr_cmds.c)
void PF_vlen (void)
{
	float *value1;
	float  new;

	value1 = G_VECTOR (OFS_PARM0);
	new = value1[0] * value1[0] + value1[1] * value1[1] + value1[2]*value1[2];
	new = sqrtf (new);                      // single precision on this port
	G_FLOAT (OFS_RETURN) = new;
}
```

**Port additions:** `pr_numstrings` and the checks `G_VALID_STRING(s)` / `G_STRING_SAFE(o)`. A QuakeC string is a byte offset into `pr_strings`; an invalid
offset (from a corrupted save, or the Playdate's 32-bit address assumptions) would otherwise read arbitrary memory. `PF_VarString` and `SV_CreateBaseline` use them.

## `pr_edict.c`

Everything about edicts and loading the program.

| Function | Purpose |
| --- | --- |
| `PR_Init` | Registers the debug commands `edict`, `edicts`, `edictcount`, `profile`, and cvars (`nomonsters`, `gamecfg`, `scratch1…4`, `saved1…4`). |
| `PR_LoadProgs` | Loads `progs.dat` (`COM_LoadHunkFile`), computes `pr_crc`, byte-swaps the header and tables, checks the version (6) and the header CRC, and sets up `pr_functions`, `pr_strings`, `pr_globaldefs`, `pr_fielddefs`, `pr_statements`, `pr_global_struct` and `pr_edict_size`. |
| `ED_Alloc` / `ED_Free` / `ED_ClearEdict` | Take a free slot (not one freed within the last 0.5 s, unless early in the level), release one. |
| `ED_LoadFromFile(data)` | Parses a map's entity text: for each `{ "key" "value" ... }` it allocates an edict, fills its fields (`ED_ParseEdict`), finds the function named by `classname` (`ED_FindFunction`) and runs it as the entity's spawn function. Entities removed by skill/deathmatch flags are dropped. |
| `ED_ParseEdict` / `ED_ParseEpair` / `ED_ParseGlobals` | Convert text values to typed fields (`float`, `vector "x y z"`, `string`, `entity`, `function`). |
| `ED_Write` / `ED_WriteGlobals` | Save an edict and the globals in the text form used by savegames. |
| `ED_Print`, `ED_PrintEdicts`, `ED_PrintNum`, `ED_Count`, `ED_PrintEdict_f` | Debug listings. |
| `ED_FindField`, `ED_FindGlobal`, `ED_FindFunction`, `ED_FieldAtOfs`, `ED_GlobalAtOfs` | Look up definitions by name or offset. |
| `GetEdictFieldValue(ed, "name")` | A cached by-name field lookup (for extensions). |
| `ED_NewString(s)` | Copy a string into the server's string heap (handles `\n`). |
| `EDICT_NUM`, `NUM_FOR_EDICT` | Bounds-checked conversions. |
| `PR_ValueString`, `PR_UglyValueString`, `PR_GlobalString` | Typed value formatting. |

```
// the entities lump of e1m1, as the engine sees it
{
"classname" "info_player_start"
"origin" "480 -352 88"
"angle" "90"
}
```

**Port change:** `pr_numstrings` is recorded; `%f` formats cast to `double`; `"???"` escaped (`\?\?\?`) to avoid trigraphs.

## `pr_exec.c`

The interpreter. `PR_ExecuteProgram(func_t)` runs a QuakeC function (and the functions it calls) to completion.

- **Frames.** `PR_EnterFunction` pushes a `prstack_t` (statement and function; at most `MAX_STACK_DEPTH` = 32 deep), saves the callee's locals on `localstack` (2048 ints), and copies parameters into the callee's local slots.
  `PR_LeaveFunction` restores them.
- **Main loop.** One `switch` over `st->op` for each statement. Arithmetic, comparison, loads, stores, `OP_IF`/`OP_IFNOT`/`OP_GOTO` (relative jumps), `OP_CALL0..8`, `OP_STATE` (set the model frame and schedule the next think),
  `OP_RETURN`/`OP_DONE`.
- **Builtins.** A function whose `first_statement` is negative is a builtin: `pr_builtins[-first_statement]()`.
- **Safety.** `runaway` counts down from 100000 statements per call (`runaway loop error`); `PR_RunError` prints the QuakeC call stack (`PR_StackTrace`) and the offending statement and drops to `Host_Error`.
  `pr_trace` (the `traceon` builtin) prints every statement (`PR_PrintStatement`).
- `PR_Profile_f` (`profile` command) prints the 10 most-executed functions.

```c
while (1) {
	s++;
	st = &pr_statements[s];
	a = (eval_t *)&pr_globals[st->a];  b = (eval_t *)&pr_globals[st->b];  c = (eval_t *)&pr_globals[st->c];
	if (!--runaway) PR_RunError ("runaway loop error");
	switch (st->op) {
	case OP_ADD_F:   c->_float = a->_float + b->_float; break;
	case OP_IF:      if (a->_int) s += st->b - 1; break;           // -1: the loop does s++
	case OP_CALL1: ...
		newf = &pr_functions[a->function];
		if (newf->first_statement < 0) { pr_builtins[-newf->first_statement] (); break; }   // builtin
		s = PR_EnterFunction (newf);
		break;
	...
```

**Port changes:** the `FPS_20` variant of `OP_STATE` was removed (a state's next think is `time + 0.1`); with `-DPD_PROFILE_FINE=ON`, `PR_ExecuteProgram` is wrapped to time the QuakeC section (`P_QC`), count statements (`C_QCOPS`) and calls (`C_QCCALLS`), and each builtin
call is timed into the per-builtin table (`pdprof_bi_add`, the `BI` lines of `prof.csv`). `PROF_STK(K_QC)` records stack depth.

## `pr_cmds.c`

The builtins, numbered as QuakeC declares them (`makevectors = #1`, `setorigin = #2`, …). `pr_builtin[]` is the table; `pr_numbuiltins` its length. Numbers with no implementation call `PF_Fixme`.

| Group | Builtins |
| --- | --- |
| Vectors and maths | `makevectors`, `normalize`, `vlen`, `vectoyaw`, `vectoangles`, `random`, `rint`, `floor`, `ceil`, `fabs` |
| Entities | `spawn`, `remove`, `find`, `findradius`, `nextent`, `setorigin`, `setsize`, `setmodel`, `makestatic`, `droptofloor` |
| World queries | `traceline`, `checkclient`, `aim`, `pointcontents`, `checkbottom`, `walkmove`, `movetogoal` (`SV_MoveToGoal`), `changeyaw` |
| Sound and effects | `sound`, `ambientsound`, `particle`, `lightstyle`, `centerprint`, `precache_sound`, `precache_model`, `precache_file` |
| Messages | `bprint`, `sprint`, `dprint`, `stuffcmd`, `WriteByte/Char/Short/Long/Coord/Angle/String/Entity` |
| Strings | `ftos`, `vtos` |
| Console and system | `cvar`, `cvar_set`, `localcmd`, `changelevel`, `setspawnparms`, `error`, `objerror`, `break`, `coredump`, `traceon`, `traceoff`, `eprint` |

```c
// PF_traceline (abridged): QuakeC asks for a line trace; the answer comes back in QuakeC globals
void PF_traceline (void)
{
	float   *v1 = G_VECTOR (OFS_PARM0), *v2 = G_VECTOR (OFS_PARM1);
	int      nomonsters = G_FLOAT (OFS_PARM2);
	edict_t *ent = G_EDICT (OFS_PARM3);
	trace_t  trace;

	trace = SV_Move (v1, vec3_origin, vec3_origin, v2, nomonsters, ent);      // world.c
	pr_global_struct->trace_allsolid = trace.allsolid;
	pr_global_struct->trace_fraction = trace.fraction;
	VectorCopy (trace.endpos, pr_global_struct->trace_endpos);
	pr_global_struct->trace_ent = trace.ent ? EDICT_TO_PROG (trace.ent) : EDICT_TO_PROG (sv.edicts);
	/* ... trace_startsolid, trace_inwater, trace_inopen, trace_plane_normal, trace_plane_dist */
}
```

`PF_aim` is the vertical auto-aim; the Playdate's [`autofire.c`](../port/playdate.md#autofirec--autofireh) mirrors its cone test (`sv_aim`, default 0.93) to decide when a monster is in the line of fire.

**Port changes:** every `sin/cos/sqrt/atan2/floor/ceil/fabs` call is the single-precision `*f` version; `PF_VarString` uses `G_STRING_SAFE`; `PF_ftos` and `PF_vtos` cast to `double` for `sprintf`.
